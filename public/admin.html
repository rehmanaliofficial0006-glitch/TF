Leaderboard Management

                
 Auto Leaderboard
Automatically rank every user using the selected metric. Display Earnings is always set automatically from each user’s Total Earnings.
 Show All Users
When ON, every user appears in the user-facing leaderboard — even those with rank 0 or PKR 0 earnings. When OFF, only users with a rank set above appear.

                

                    

                        

                            Set the rank and display earnings for users. Users with a rank will appear on the leaderboard, sorted by their rank number (1 is highest). Leave rank blank to remove a user from the leaderboard.
